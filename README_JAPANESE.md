## 👁️ 概要 (Overview)

**『THE ECHO CHAMBER』**は、地下再教育施設の深部を舞台とした、閉塞感あふれる一人称視点の心理サスペンス＆ナラティブ・シミュレーションゲームです。

薄暗いコンクリートのバンカーの中、明滅する巨大なCRTモニターの壁に向かい合い、あなたは**スズキ・カイト博士**となります。彼の唯一の仕事は、夜間監視員として反体制分子の精神をシステム的に消去・改ざんすることです。
